# Prime Desktop 💻

Официальный клиент **Prime Messenger** для Windows 10/11, написанный на **C# (.NET 8 WPF)**. Обеспечивает прямое P2P-взаимодействие со смартфонами на Android и другими ПК по протоколу **Bluetooth RFCOMM** без промежуточных серверов, облаков и внешнего интернета.

## ⚡ Ключевые возможности

### 📡 Чистый Bluetooth RFCOMM
* **Прямая P2P связь:** соединение со смартфоном напрямую по стандартному Bluetooth RFCOMM (UUID: `fa87c0d0-afac-11de-8a39-0800200c9a66`).
* **Полная совместимость пакетов:** бинарная совместимость с Android-клиентом (типы `0x01`–`0x0F`: текст, статус, аватар, эхо/пинг, фото, видео, файлы, реакции, форматирование, голосовые, видеозаметки).
* **Автоматическое согласование ролей (Role Arbitration):** синхронизация клиентов без коллизий соединения (Java HashCode-совместимое сравнение адресов).
* **Мгновенное обнаружение сопряжённых устройств:** старт сканирования занимает ~50 мс без 30-секундных задержек inquiry.
* **Очередь исходящих (Outbox):** автоматическая досылка сообщений и вложений при временном обрыве связи сразу после восстановления канала.
* **Индикация передачи в реальном времени:** визуальные кольцевые оверлеи, прогресс-бары и расчёт скорости в КБ/с для отправки и приёма фото, коллажей, видео, видеокружков и файлов.

### 🎨 Современный интерфейс (WPF Fluent / Dark Mode)
* **Адаптивный 2-панельный интерфейс:** быстрый список чатов, поиск, профиль пользователя и диалоговое окно.
* **Буфер обмена (Ctrl + V):** прямая вставка скриншотов из буфера, изображений и файлов с поддержкой коллажей.
* **Медиа-сообщения:**
  * Просмотр изображений и фотогалерея.
  * Видеозаметки («кружочки») с адаптивным скруглением и предпросмотром.
  * Голосовые сообщения с отрисовкой аудио-волны (waveform) и ускорением воспроизведения (1x / 1.5x / 2x).
  * OpenGraph превью для веб-ссылок.
  * Расширенное форматирование текста (жирный, курсив, моноширинный, цитаты, спойлеры).
  * Реакции смайликами и ответы на сообщения (Reply).

## 🛠 Сборка из исходников

> [!TIP]
> Подробная инструкция по первичному развёртыванию на новом ноутбуке или ПК: **[SETUP_LAPTOP.md](SETUP_LAPTOP.md)**.

### Требования
* Windows 10 (версия 19041+) или Windows 11
* [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)

### Быстрая сборка через скрипт
В корне папки `desktop/` запустите:
```cmd
cd desktop
build.bat
```
Скрипт автоматически:
1. Скомпилирует `PrimeDesktop.exe` в режиме Release (Self-Contained Single File).
2. Соберёт инсталлятор `PrimeSetup.exe` в папку `desktop/bin/Installer/`.

### Ручная сборка и запуск
```cmd
cd desktop/PrimeDesktop
dotnet run
```
