## Быстрый запуск

1. Скачайте [PrimeSetup.exe](https://github.com/Vaniahorosh/Prime_messenger_Desktop/releases/latest/download/PrimeSetup.exe).
2. Запустите файл и нажмите кнопку "Установить".
3. Откройте Prime Desktop через ярлык на рабочем столе или в меню Пуск.

Если установка не требуется, используйте [PrimeDesktop.exe](https://github.com/Vaniahorosh/Prime_messenger_Desktop/releases/latest/download/PrimeDesktop.exe): файл можно скопировать в любую папку или на USB-накопитель и запустить напрямую.

## Принцип работы

Prime Desktop работает как независимый узел (peer) и подключается напрямую к мобильным устройствам Android и рабочим станциям в радиусе действия радиоканала или подсети:

- **Bluetooth RFCOMM**: прямое соединение через стандартный последовательный профиль (сервисный UUID: `fa87c0d0-afac-11de-8a39-0800200c9a66`).
- **Локальная сеть LAN**: автоматический поиск доступных пиров по UDP (порт `8988`) и быстрая передача данных по прямому TCP-каналу (порт `8989`).
- **Сетевой протокол PrimePacket**: единый формат бинарных пакетов с типами от `0x01` до `0x0F` (текст, аватары, фото, видеозаметки, аудиосообщения, реакции и файлы).
- **Очередь доставки (Outbox)**: гарантированная отправка сообщений и вложений при временных разрывах радиосвязи.

## Архитектура: C# WPF и Rust Core

Приложение построено по модульной гибридной схеме:

```
[ Пользовательский интерфейс WPF (.NET 8) ]
       │ P/Invoke (C-ABI)
[ Нативное ядро PrimeNative (Rust cdylib: prime_native.dll) ]
```

| Компонент | Технологический стек | Зона ответственности |
| :--- | :--- | :--- |
| **Интерфейс и медиа** | C#, .NET 8, WPF, WebView2 | Окна с эффектом матового стекла, вкладки браузера, плеер аудиозаметок с отображением звуковой волны, галереи вложений и системный трей |
| **Нативное ядро** | Rust, AES-GCM, Blake3, SHA-2 | Аппаратное шифрование AES-256-GCM, расчет контрольных сумм Blake3/SHA-256, 5-байтовое кадрирование пакетов и маскирование аппаратных идентификаторов |
| **Сетевой стек** | Windows WinRT, Sockets | Bluetooth RFCOMM сокеты и параллельный UDP/TCP транспорт для локальной сети |

При отсутствии библиотеки `prime_native.dll` клиент автоматически переключается на встроенную управляемую криптографию .NET без сбоев в работе.

## Основные возможности клиента

- **Форматирование и медиа**: передача файлов любого типа, умный коллаж фото, видеозаметки, цитирование ответов и разметка текста.
- **Голосовые заметки**: запись и воспроизведение с динамической отрисовкой звуковой волны и переключением скорости (1.0x, 1.5x, 2.0x).
- **Встроенный браузер**: веб-просмотр страниц на базе WebView2 с вкладками, закладками и изолированным профилем.
- **Интерфейс**: адаптивная двухрежимная боковая панель (стандартная 320px и компактная 72px) и регулируемые разделители панелей.

## Сборка из исходников

### Требования
- Windows 10 (версия 19041+) или Windows 11 x64
- .NET 8.0 SDK
- Rust 1.80+ (опционально, если требуется перекомпиляция `prime_native.dll`)

### Автоматическая сборка
Выполните скрипт в командной строке:
```cmd
cd desktop
build.bat
```

Скрипт автоматически:
1. Компилирует Rust-ядро в `desktop/PrimeNative/target/release/prime_native.dll` (при наличии Cargo).
2. Синхронизирует библиотеку с проектом `PrimeDesktop`.
3. Собирает автономный исполняемый файл в `desktop/bin/Portable/PrimeDesktop.exe`.
4. Формирует графический мастер установки в `desktop/bin/Installer/PrimeSetup.exe`.

### Запуск в режиме разработки
```cmd
cd desktop\PrimeDesktop
dotnet run
```
