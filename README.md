## 🚀 О проекте

**Prime Desktop** — официальный настольный клиент экосистемы Prime Messenger. Приложение обеспечивает защищённое одноранговое (P2P) общение без участия сторонних серверов, облачных провайдеров и внешнего подключения к интернету.

Связь с мобильными устройствами Android и другими рабочими станциями осуществляется напрямую:
- **Bluetooth RFCOMM** (стандартный профиль последовательного порта).
- **Локальная сеть LAN** (автоматическое UDP-обнаружение и прямой TCP-транспорт).

## ⚡ Архитектура: C# WPF + Rust Native Core

В проекте реализована **единая гибридная архитектура**, объединяющая лучшие стороны двух платформ:

1. **Интерфейс и бизнес-логика — C# (.NET 8 WPF):**
   - Нативный интерфейс Windows с аппаратным эффектом акрилового матового стекла (Frosted Glassmorphism).
   - Встроенный многовкладочный браузер (WebView2) с изоляцией вкладок и закладками.
   - Воспроизведение и запись аудиозаметок с интерактивной звуковой волной (waveform) и ускорением.
   - Коллажи фото и галереи вложений, цитирование сообщений и гибкое форматирование.

2. **Нативное ядро криптографии и протокола — Rust (`prime_native.dll`):**
   - Сверхбыстрое и безопасное сквозное шифрование **AES-256-GCM**.
   - Криптографическое хеширование **Blake3** и **SHA-256** для проверки целостности пакетов и файлов.
   - 5-байтовое кадрирование протокола **PrimePacket** на уровне нативной памяти без лишних аллокаций.
   - Маскирование и анонимизация аппаратных MAC/Bluetooth идентификаторов.
   - **Автоматический Fallback:** если нативная библиотека отсутствует, клиент прозрачно переключается на встроенную управляемую реализацию .NET.

## 📦 Варианты поставки

Клиент собирается в двух готовых форматах (каталог `desktop/bin/`):

1. **Портативная версия (Portable)**:
   - Исполняемый файл: `desktop/bin/Portable/PrimeDesktop.exe`
   - Полностью автономная (Self-Contained) сборка.
   - Не требует установки в операционную систему и прав администратора.
   - Не требует предварительной установки .NET Runtime.
   - Подходит для запуска с внешних USB-накопителей или любой локальной папки.

2. **Версия с установщиком (Installer)**:
   - Исполняемый файл: `desktop/bin/Installer/PrimeSetup.exe`
   - Удобный графический мастер установки.
   - Позволяет выбрать каталог для размещения программы.
   - Создаёт ярлыки на рабочем столе и в меню «Пуск».
   - Автоматически распаковывает все компоненты и регистрирует приложение.

## ✨ Основные возможности

### Одноранговая сеть и протокол
- **Прямое P2P-соединение:** работа по Bluetooth RFCOMM (UUID: `fa87c0d0-afac-11de-8a39-0800200c9a66`) и TCP/IP (порт `8989`).
- **Автоматическое обнаружение пиров** в локальной сети по UDP (порт `8988`).
- **Единый протокол PrimePacket:** 100% совместимость типов пакетов (`0x01`–`0x0F`) с Android-клиентом.
- **Очередь отправки (Outbox):** гарантированная доставка сообщений и файлов при временном разрыве соединения.
- **Сквозное шифрование:** аппаратное ускорение AES-256-GCM через нативное Rust-ядро.

### Интерфейс и дизайн
- **Эффект матового стекла (Frosted Glassmorphism):** аппаратное размытие фона поверх контента.
- **Плавное затемнение:** виньетки сверху и снизу области сообщений.
- **Двухрежимная боковая панель:** стандартный список диалогов (320px) и компактный режим аватарок (Rail, 72px).
- **Панель информации о собеседнике:** вкладки «Медиа», «Файлы», «Аудио» с триггером смахивания.
- **Плавные сплиттеры:** защита от мерцания при изменении размеров панелей.

### Медиа и функции связи
- Передача любых файлов, изображений, видеозаметок и архивов с адаптивным коллажем фото.
- Голосовые сообщения с отрисовкой звуковой волны (waveform) и переключением скорости (1.0x / 1.5x / 2.0x).
- Реакции, цитирование ответов и разметка текста (жирный, курсив, спойлеры).
- Встроенный веб-браузер с вкладками, историей и закладками.

## 🛠 Сборка из исходного кода

### Требования
- **ОС:** Windows 10 (версия 19041+) или Windows 11 (x64).
- **.NET:** .NET 8.0 SDK (x64).
- **Rust (опционально):** Rust 1.80+ (если требуется перекомпиляция `prime_native.dll`). При отсутствии Cargo скрипт использует готовое нативное ядро или встроенный C# fallback.

### Быстрая сборка (одной командой)
Запустите единый сборочный скрипт:
```cmd
cd desktop
build.bat
```

Скрипт автоматически:
1. Проверяет наличие Rust и при наличии пересобирает `PrimeNative` в релизную библиотеку `prime_native.dll`.
2. Копирует актуальную `prime_native.dll` в проект `PrimeDesktop`.
3. Собирает релизный портативный исполняемый файл `PrimeDesktop.exe` в `desktop/bin/Portable/`.
4. Собирает мастер установки `PrimeSetup.exe` в `desktop/bin/Installer/`.

### Запуск в режиме разработки
```cmd
cd desktop\PrimeDesktop
dotnet run
```
или откройте `desktop\PrimeDesktop.sln` в **Visual Studio 2022** и нажмите `F5`.
