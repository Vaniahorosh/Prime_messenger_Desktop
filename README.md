## Описание проекта

Prime Desktop - официальный десктопный клиент экосистемы Prime Messenger. Приложение обеспечивает защищенное одноранговое (P2P) общение без участия сторонних серверов, облачных провайдеров и внешнего подключения к интернету.

Связь с мобильными устройствами Android и другими рабочими станциями осуществляется напрямую:
- Через Bluetooth RFCOMM (стандартный профиль последовательного порта).
- Через локальную сеть LAN (автоматическое UDP-обнаружение и прямой TCP-транспорт).

В репозитории представлены две реализации клиента:
1. **WPF Client (C# / .NET 8)** - полнофункциональная версия с расширенным медиа-плеером, записью голосовых заметок и встроенным многовкладочным браузером.
2. **Rust Client (Tauri 2.0 / Tokio / SQLite)** - ультралегковесная нативная версия с минимальным потреблением оперативной памяти (~48 МБ) и запуском без внешних зависимостей.

## Варианты поставки

Приложение доступно в двух вариантах:

1. **Портативная версия (Portable)**:
   - Исполняемый файл: `desktop/bin/Portable/PrimeDesktop.exe`
   - Полностью автономная (Self-Contained) сборка.
   - Не требует установки в операционную систему и прав администратора.
   - Не требует предварительной установки .NET Runtime или дополнительных библиотек.
   - Подходит для запуска с внешних USB-накопителей или любой локальной папки.

2. **Версия с установщиком (Installer)**:
   - Исполняемый файл: `desktop/bin/Installer/PrimeSetup.exe`
   - Графический мастер установки приложения.
   - Позволяет выбрать каталог для размещения программы.
   - Создает ярлыки на рабочем столе и в меню Пуск.
   - Автоматически распаковывает все необходимые компоненты и регистрирует приложение в системе.

## Основные возможности

### Одноранговая сеть и протокол
- Прямое P2P-соединение: работа по Bluetooth RFCOMM (UUID: `fa87c0d0-afac-11de-8a39-0800200c9a66`) и TCP/IP (порт 8989).
- Автоматическое обнаружение пиров в локальной сети по UDP (порт 8988).
- Единый 5-байтовый протокол кадрирования PrimePacket: гарантированная совместимость типов пакетов с Android-клиентом.
- Очередь отправки (Outbox): гарантированная доставка сообщений и файлов при временном разрыве соединения.
- Сквозное шифрование: поддержка алгоритма AES-256-GCM.

### Интерфейс и дизайн
- Эффект матового стекла (Frosted Glassmorphism): аппаратное размытие фона поверх контента.
- Плавное затемнение (виньетки от 0 до 50% сверху и снизу области сообщений).
- Двухрежимная боковая панель: стандартный список диалогов (320px) и компактный режим аватарок (Rail, 72px) с автозакрытием поиска.
- Панель информации о собеседнике: вкладки «Медиа», «Файлы», «Аудио» с триггером смахивания при перетягивании к краю окна.
- Плавные сплиттеры с защитой от мерцания и дребезга при изменении размеров панелей.

### Медиа и функции связи
- Отправка и прием любых файлов, изображений, видеозаметок и архивов.
- Голосовые сообщения с отрисовкой звуковой волны (waveform) и управлением скоростью воспроизведения (1.0x / 1.5x / 2.0x).
- Поддержка реакций, цитирования и форматирования текста (жирный, курсив, моноширинный, спойлеры).
- Встроенный веб-браузер (в C#-клиенте) с вкладками, историей, закладками и поддержкой горячих клавиш.

## Сборка из исходного кода

### 1. Сборка клиента C# (.NET 8 WPF)

Требования:
- Windows 10 (версия 19041+) или Windows 11.
- .NET 8 SDK.

Автоматическая сборка портативной версии и установщика:
```cmd
desktop\build.bat
```

После выполнения скрипта в каталоге `desktop/bin/` формируются:
- `desktop/bin/Portable/PrimeDesktop.exe` - портативная версия.
- `desktop/bin/Installer/PrimeSetup.exe` - версия с графическим установщиком.

### 2. Сборка нативного клиента Rust (Tauri 2.0)

Требования:
- Rust 1.80+ (toolchain `x86_64-pc-windows-gnu` с MinGW или MSVC).
- WebView2 Runtime (встроен в Windows 10/11).

Команда сборки:
```cmd
cd desktop_rust
cargo build --release
```
Исполняемый файл создается в каталоге `desktop_rust/target/release/prime-desktop.exe`.
