## Описание проекта

Prime Desktop - официальный десктопный клиент экосистемы Prime Messenger, полностью переписанный на языке программирования **Rust** с использованием нативного фреймворка **Tauri 2.0**, асинхронного рантайма **Tokio** и встроенной базы данных **SQLite**.

Приложение обеспечивает прямое одноранговое (P2P) общение без промежуточных серверов, облачных сервисов и внешнего подключения к интернету:
- Прямая связь по протоколу Bluetooth RFCOMM со смартфонами на Android и ПК.
- Работа в локальной сети LAN через автоматическое UDP-обнаружение и прямые TCP-потоки.

## Преимущества архитектуры на Rust

1. Экстремальная производительность и легковесность:
   - Потребление оперативной памяти: всего ~48-53 МБ.
   - Мгновенный холодный запуск за доли секунды.
   - Отсутствие зависимости от сторонних сред исполнения (.NET Runtime, Java, Node.js).
2. Надежность и безопасность памяти (Memory Safety):
   - Исключены ошибки обращения по нулевому указателю и утечки ресурсов.
   - Потокобезопасная асинхронная обработка сетевых пакетов на пуле потоков Tokio.
3. Полная бинарная совместимость:
   - Стандартный 5-байтовый протокол кадрирования пакетов PrimePacket.
   - Аппаратное шифрование AES-256-GCM.
4. Встроенное локальное хранилище:
   - База данных SQLite с индексацией истории сообщений и чатов.

В корневом каталоге проекта находится файл для запуска в один клик:

- `Запустить Prime.bat` - мгновенный запуск скомпилированного нативного клиента.

## Дизайн и пользовательский интерфейс

- Эффект матового стекла (Frosted Glassmorphism): аппаратно-ускоренное размытие фона (`backdrop-filter: blur(28px) saturate(180%)`) на парящих островках чата и панели ввода.
- Плавные градиентные виньетки (затемнение от 0 до 50% сверху и снизу), под которые мягко заходит лента сообщений.
- Двухрежимная боковая панель диалогов:
  - Режим только аватарок (Rail, 72px) с центрированием и быстрым переходом в профиль.
  - Полноразмерный список контактов (320px) с поиском и метаданными.
- Панель информации о собеседнике с вкладками «Медиа», «Файлы», «Аудио» и триггером смахивания при перетягивании к краю окна.
- Плавные интерактивные разделители с защитой от мерцания и дребезга.

## Сборка из исходного кода

### Требования
- Язык программирования Rust 1.80+ (рекомендуется toolchain `stable-x86_64-pc-windows-gnu` с MinGW или MSVC).
- WebView2 Runtime (встроен в Windows 10/11).

### Команда сборки
```cmd
cargo build --release
```

Скомпилированный исполняемый файл создается по пути:
`target/release/prime-desktop.exe`
