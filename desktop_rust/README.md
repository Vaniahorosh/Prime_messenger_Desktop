# Prime Desktop - Нативная версия на Rust и Tauri 2.0

Нативный сверхбыстрый и легковесный клиент Prime Messenger для Windows, полностью перенесённый с C# (.NET 8 WPF) на язык **Rust** с применением фреймворка **Tauri 2.0**, асинхронного рантайма **Tokio**, базы данных **SQLite** и аппаратного ускорения **WebView2**.

---

## 🚀 Ключевые преимущества версии на Rust

1. **Производительность и ультра-низкое потребление ресурсов**:
   - Потребление оперативной памяти: **~48–55 МБ** (по сравнению со 180–300 МБ у C# WPF/WebView2).
   - Запуск приложения за **доли секунды** (0.1–0.2 с).
   - Полное отсутствие зависимости от тяжелых .NET рантаймов (приложение полностью нативное, скомпилировано в машинный код).

2. **Безопасность и надежность памяти**:
   - Гарантированная защита от исключений `NullReferenceException`, Data Races и утечек памяти на уровне компилятора Rust.
   - Потокобезопасная асинхронная архитектура на базе Tokio.

3. **100% совместимость с бинарным протоколом Prime Messenger**:
   - **5-байтовое кадрирование** пакетов: `[PacketType: 1B][Length: 4B Big-Endian][Payload]`.
   - **LAN Discovery (UDP 8988)**: широковещательные запросы `PRIME_PC_DISCOVER` и ответы `PRIME_PEER:ip=...;name=...;login=...;port=8989`.
   - **TCP P2P Транспорт (порт 8989)**: прямое peer-to-peer соединение между смартфонами Android и компьютерами.
   - **Bluetooth Classic (RFCOMM)**: обнаружение сопряженных устройств (например, Pixel 10), роль-арбитраж (`IsClientInitiator`) и анонимизация MAC-адресов.
   - **Хэндшейк версии 100**: для полной совместимости с Android-клиентом и предотвращения диалога несовместимости версий (`version=100`).
   - Чанкование файлов и медиа по **16 КБ** со сбросом потока (`flush`).
   - Сквозное шифрование **AES-256-GCM**.

4. **Анонимизация устройств (Hardware Privacy)**:
   - Полное сокрытие реальных MAC-адресов, Bluetooth ID и IP-адресов за детерминированными хеш-идентификаторами `peer_{sha256[..8]}`.

## 🎨 Детально перенесенные функции из версии C# WPF

- **Встроенный приватный браузер («Prime Browser»)**:
  - Многовкладочный интерфейс с кнопками создания и закрытия вкладок.
  - Навигационная панель: Назад, Вперёд, Перезагрузка, Домой, ввод URL и встроенный поиск DuckDuckGo.
  - Панель закладок и сохранение истории посещений в базу данных SQLite (`browser_history`, `browser_bookmarks`).
- **Встроенный фоторедактор («Фоторедактор Прайм»)**:
  - Полнофункциональный холст для рисования кистью с выбором толщины и фирменной цветовой палитрой.
  - Геометрические трансформации: поворот на 90° по часовой стрелке, отражение по горизонтали и вертикали.
  - Коррекция цвета в реальном времени: ползунки яркости, контрастности и насыщенности.
  - Отмена штрихов, сохранение на диск и прямая отправка отредактированного снимка в чат («✓ Применить и отправить»).
- **Круглые видеосообщения («Кружочки» Telegram-style)**:
  - Круглый плеер с круговой обрезкой и кольцевым индикатором воспроизведения.
  - Переключение скорости воспроизведения (1.0x / 1.5x / 2.0x).
  - Пауза и воспроизведение по клику на видео.
- **Голосовые сообщения с интерактивной аудио-волной**:
  - Запись с микрофона через кнопку микрофона в строке ввода сообщения с таймером и кнопками отмены/отправки.
  - Визуализатор формы волны (Waveform) с градиентной подсветкой прослушанной части и возможностью перемотки.
- **Математический синтез звуковых эффектов (Sound Effects)**:
  - Процедурная генерация звуков без внешних тяжелых WAV-файлов: отправка сообщения (`Sent`), получение (`Received`), старт/стоп записи войса (`RecordStart`/`RecordStop`), всплытие реакций (`Pop`).
  - Воспроизведение через Win32 `PlaySoundW` из памяти с нулевой задержкой.
- **Безопасность и защита от утечек**:
  - Аппаратная защита окна от захвата экрана и скриншотов через Win32 API `SetWindowDisplayAffinity(hwnd, WDA_MONITOR)`.
  - Защитный полупрозрачный диагональный водяной знак (Watermark) с ID пользователя.
  - Защита приложения 4-значным **PIN-кодом** с интерактивной клавиатурой и вибро-анимацией ошибки при неверном вводе.
- **Движок тем и акцентных цветов**:
  - Темы: Тёмная (Dark Onyx), Светлая (Light Fluent), OLED (Глубокий чёрный), Cyberpunk (Неон), Emerald Prime (Изумруд).
  - Выбор акцентного цвета из палитры + инструмент **Экранная пипетка (Eyedropper)**.
  - Настройка скругления уголков сообщений (от 4 до 24px) и прозрачности обоев чата.
- **Эмодзи и быстрые реакции**:
  - Панель реакций при наведении и контекстном меню (👍, ❤️, 🔥, 😂, 👏, 🎉, 💯, 😢).
  - Категоризированный пикер эмодзи (Смайлики, Жесты, Природа, Еда, Активности, Предметы, Символы).
- **Сплывающие уведомления (Toast Notifications)**:
  - Плавающие карточки уведомлений с аватаром отправителя, предпросмотром текста и переходом в чат по клику.

## 📁 Структура проекта

```text
desktop_rust/
├── build_rust.bat              # Скрипт быстрой сборки Release-версии
├── run_prime_rust.bat          # Скрипт мгновенного запуска скомпилированного клиента
├── Cargo.toml                  # Зависимости Rust (Tauri 2, Tokio, SQLite, AES-GCM, Chrono)
├── tauri.conf.json             # Конфигурация окна Tauri 2.0, трея и разрешений
├── src/
│   ├── main.rs                 # Точка входа, трей-меню, Tokio runtime и IPC-обработчики
│   ├── anonymizer.rs           # Анонимизация MAC, IP и Bluetooth ID в peer_xxxx
│   ├── bluetooth.rs            # Обнаружение Bluetooth Classic устройств (Pixel 10) через Win32
│   ├── commands.rs             # 29 команд Tauri IPC (чаты, сообщения, войсы, фото, браузер, PIN)
│   ├── crypto.rs               # Сквозное шифрование AES-256-GCM с 12-байтным nonce
│   ├── link_preview.rs         # Извлечение URL и генерация OpenGraph карточек
│   ├── models.rs               # Модели данных (PacketType, ChatMessage, UserSettings, Bluetooth)
│   ├── network.rs              # Многопоточный TCP 8989, UDP 8988 LAN сканер, KeepAlive, Outbox
│   ├── protocol.rs             # 5-байтовое кадрирование пакетов Prime и парсеры
│   ├── sound.rs                # Процедурный математический синтез WAV звуков (PlaySoundW)
│   └── storage.rs              # SQLite хранилище с WAL-режимом (чаты, сообщения, браузер, настройки)
└── ui/
    ├── index.html              # Разметка UI: чат, островки, Prime Браузер, Фоторедактор, PIN-экран
    ├── styles/
    │   └── prime.css           # Glassmorphism стили, матовое стекло, виньетки, темы, анимации
    └── scripts/
        └── app.js              # Реактивная логика UI, аудиозапись, браузер, рисование, события
```

## 🛠 Сборка и запуск

### Быстрый запуск готового клиента:
```cmd
run_prime_rust.bat
```

### Сборка из исходного кода:
```cmd
build_rust.bat
```
или напрямую через Cargo:
```cmd
cargo build --release
```

Готовый бинарный файл создается в `target/release/prime-desktop.exe`.
