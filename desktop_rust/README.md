# Prime Desktop — Нативная версия на Rust & Tauri 2.0

Нативный легковесный клиент Prime Desktop, переписанный на **Rust** с использованием фреймворка **Tauri 2.0** и асинхронного рантайма **Tokio**.

---

## Преимущества переписывания на Rust

1. **Производительность и потребление памяти:**
   - Потребление ОЗУ в 4–5 раз меньше по сравнению с полным WPF / CEF стеком.
   - Быстрый холодный запуск за доли секунды.
2. **Безопасность и надёжность (Memory & Concurrency Safety):**
   - Полное отсутствие `NullReferenceException` и утечек памяти.
   - Потокобезопасная асинхронная архитектура на базе Tokio.
3. **Совместимость с протоколом Prime:**
   - 5-байтовое кадрирование пакетов (`[Type: 1B][Length: 4B BigEndian][Payload]`).
   - UDP discovery на порту `8988` (`PRIME_PC_DISCOVER` <-> `PRIME_PEER:...`).
   - TCP P2P соединения на порту `8989`.
   - Поддержка шифрования AES-256-GCM.
4. **База данных:**
   - Быстрая встроенная SQLite (`rusqlite`) с индексами по чатам и сообщениям.
5. **Дизайн Prime с эффектом матового стекла (Frosted Glassmorphism):**
   - Аппаратно-ускоренные островки с `backdrop-filter: blur(28px) saturate(180%)`.
   - Плавное затемнение сверху и снизу (виньетки от 0 до 50%).
   - Контент чата плавно заходит под шапку и островок ввода.
   - Двухрежимный сайдбар: компактный режим аватарок (Rail, 72px) и стандартный список контактов (320px) с умным сжатием и сбросом поиска.
   - Панель собеседника с вкладками «Медиа», «Файлы», «Аудио» и триггером смахивания при перетягивании.

## Структура проекта

```
desktop_rust/
├── bin/
│   └── release/
│       └── prime-desktop.exe       # Готовый нативный исполняемый файл
├── src/
│   ├── main.rs                    # Точка входа Tauri приложения и инициализация сервисов
│   ├── models.rs                  # Модели данных (PacketType, ChatMessage, UserSettings и др.)
│   ├── protocol.rs                # Кадрирование, парсинг и сборка пакетов Prime
│   ├── network.rs                 # UDP обнаружение (8988) и TCP P2P транспорт (8989)
│   ├── crypto.rs                  # AES-256-GCM шифрование
│   ├── storage.rs                 # SQLite хранилище (prime_v2.db)
│   └── commands.rs                # Tauri IPC команды для фронтенда
├── ui/
│   ├── index.html                 # Разметка с островками, сплиттерами и вкладками
│   ├── styles/
│   │   └── prime.css              # Стили матового стекла, виньеток и анимаций
│   └── scripts/
│       └── app.js                 # Логика UI, перетягивание сплиттеров и вызовы Tauri IPC
├── Cargo.toml                     # Зависимости Rust
├── tauri.conf.json                # Конфигурация Tauri 2.0
└── build.rs                       # Tauri build-скрипт
```

## Сборка из исходников

Требования:
- Rust 1.80+ (рекомендуется `x86_64-pc-windows-gnu` с MinGW toolchain)
- WebView2 Runtime (предустановлен в Windows 10/11)

Команда сборки:
```bash
cargo build --release
```

Готовый бинарник будет расположен в `target/release/prime-desktop.exe`.
