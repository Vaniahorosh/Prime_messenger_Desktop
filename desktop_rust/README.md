# Prime Desktop - Нативная версия на Rust и Tauri 2.0

Нативный легковесный клиент Prime Desktop, реализованный на языке Rust с применением фреймворка Tauri 2.0, асинхронного рантайма Tokio и базы данных SQLite.

---

## Преимущества реализации на Rust

1. Производительность и потребление ресурсов:
   - Потребление оперативной памяти: ~48-53 МБ.
   - Быстрый запуск приложения за доли секунды.
2. Безопасность и надежность:
   - Полное отсутствие исключений обращения по нулевому указателю и утечек памяти.
   - Потокобезопасная асинхронная архитектура на базе Tokio.
3. Совместимость с протоколом Prime:
   - 5-байтовое кадрирование пакетов ([Type: 1B][Length: 4B BigEndian][Payload]).
   - UDP discovery на порту 8988 (PRIME_PC_DISCOVER и PRIME_PEER).
   - TCP P2P соединения на порту 8989.
   - Поддержка шифрования AES-256-GCM.
4. Встроенное хранилище:
   - База данных SQLite с индексами по чатам и сообщениям.
5. Дизайн Prime с эффектом матового стекла (Frosted Glassmorphism):
   - Аппаратно-ускоренные островки с backdrop-filter blur.
   - Плавное затемнение сверху и снизу (виньетки от 0 до 50%).
   - Контент чата проходит под шапкой диалога и островком ввода.
   - Двухрежимная боковая панель: режим аватарок (Rail, 72px) и стандартный список (320px).
   - Панель информации о собеседнике с вкладками «Медиа», «Файлы», «Аудио» и триггером смахивания.

## Структура проекта

```text
desktop_rust/
├── bin/
│   └── release/
│       ├── prime-desktop.exe       # Готовый нативный исполняемый файл
│       └── WebView2Loader.dll      # Системный загрузчик WebView2
├── src/
│   ├── main.rs                     # Точка входа приложения и запуск рантайма Tokio
│   ├── models.rs                   # Модели данных (PacketType, ChatMessage, UserSettings)
│   ├── protocol.rs                 # Кадрирование, парсинг и сборка пакетов Prime
│   ├── network.rs                  # UDP обнаружение (8988) и TCP P2P транспорт (8989)
│   ├── crypto.rs                   # Шифрование AES-256-GCM
│   ├── storage.rs                  # Хранилище SQLite (prime_v2.db)
│   └── commands.rs                 # Tauri IPC команды для взаимодействия с UI
├── ui/
│   ├── index.html                  # Разметка чата, островков и боковых панелей
│   ├── styles/
│   │   └── prime.css               # Стили матового стекла, виньеток и анимаций
│   └── scripts/
│       └── app.js                  # Логика UI, перетягивание сплиттеров и вызовы Tauri IPC
├── Cargo.toml                      # Зависимости Rust
├── tauri.conf.json                 # Конфигурация Tauri 2.0
└── build.rs                        # Сборочный скрипт Tauri
```

## Сборка из исходного кода

Требования:
- Rust 1.80+ (рекомендуется toolchain x86_64-pc-windows-gnu с MinGW или MSVC).
- WebView2 Runtime (встроен в Windows 10/11).

Команда сборки:
```cmd
cargo build --release
```

Готовый исполняемый файл создается по пути `target/release/prime-desktop.exe`.
